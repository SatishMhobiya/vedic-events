## 🚀 How to Run

### Quick Start (3 Steps):

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm start

# 3. Open browser
# Automatically opens at http://localhost:3000
```

### Build for Production:

```bash
npm run build
```

Creates optimized production build in `build/` folder.
